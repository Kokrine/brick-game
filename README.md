# Brick Game

Classic handheld Brick Game simulator for iPhone and the browser: 8 games (Tetris, Snake, Racing, Tank, Shooter, Breakout, Frogger, Ping-Pong) with 8-bit sounds.

Open `index.html` in a browser, or enable GitHub Pages to play from a link.

Controls: arrows, Space (rotate), Enter (start/pause), M (sound), O (on/off).
